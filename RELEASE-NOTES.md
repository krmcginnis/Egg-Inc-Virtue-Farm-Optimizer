- Removed the Load from Egg Inc panel. The Egg Inc ID field and green import arrow now sit to the left of Start from Scratch and the farm file buttons.

Use Update App → Update & Restart from v0.7.2. If still using v0.7.0 or v0.7.1, save your farm and plan, close the launcher and extract this release’s Egg-Inc-Virtue-Farm-Optimizer.zip into the existing app folder once, replacing app files.
